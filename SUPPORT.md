# Support

If you need help with Musor, please start with the project documentation in the README.

## Before asking for help

- read the installation instructions
- confirm you are using the supported Python version
- try the CLI help command:

```bash
musor --help
```

## How to ask for help

Use a GitHub issue when you are reporting a bug, a missing feature, or a problem with setup or usage.

Please include:

- your operating system
- your Python version
- the exact command you ran
- the full error output or screenshots if relevant
- the expected behavior and the actual behavior

## Questions

For general questions, open an issue using the relevant template. If the project later adds a Discussions board, that will become the preferred place for general help.

## Security issues

Do not report vulnerabilities in the public issue tracker. Please use the private security reporting process described in [SECURITY.md](SECURITY.md).
