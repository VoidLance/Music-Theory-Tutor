# Security Policy

## Supported versions

This project is currently maintained as a lightweight educational CLI and may evolve quickly. The project maintainers generally support the latest version in the default branch.

## Reporting a vulnerability

Please do not open a public GitHub issue for security vulnerabilities.

Instead, report privately using one of these methods:

- the GitHub Security tab for the repository, if available
- a private report to the project maintainer through GitHub's private channels
- an advisory submitted through the repository's security workflow

Provide as much detail as possible, including:

- a summary of the issue
- affected version or branch
- steps to reproduce
- the potential impact
- any suggested mitigation or fix

## Response expectations

We aim to acknowledge valid security reports promptly and to work on a fix as quickly as possible. Because this is a small project, response times may vary depending on maintainer availability.

## Responsible disclosure

We ask that reporters allow a reasonable amount of time for a fix to be prepared before disclosing the issue publicly. We appreciate responsible disclosure and will credit reporters when appropriate.
